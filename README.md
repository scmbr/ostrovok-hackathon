# Бронь без сюрпризов

Прототип агентной системы для трека «О!дин шаг до идеального отеля» (Хакатон Островка 2026): система узнаёт об отелях то, чего нет в карточке, и говорит, откуда это знает.

> Каркас (этап 1, задача 1). Остальные разделы README будут дополнены на этапе упаковки.

## Быстрый старт

```sh
git clone <repo>
cp .env.example .env
docker compose up --build
```

Откройте http://localhost:8080. Проверка: `curl http://localhost:8080/health` → `{"status":"ok"}`.

## Переменные окружения

| Переменная     | По умолчанию | Описание                                                  |
| -------------- | ------------ | --------------------------------------------------------- |
| `LLM_BASE_URL` | —            | OpenAI-совместимый endpoint                               |
| `LLM_API_KEY`  | пусто        | Без ключа приложение работает в режиме кеша (без LLM)     |
| `LLM_MODEL`    | —            | Имя модели                                                |
| `PORT`         | `8080`       | Порт приложения                                           |
| `DATABASE_URL` | задан в compose | Подключение к Postgres                                 |

## Моки и имитации

В демо часть данных — **мок**, он помечен и воспроизводится командами `collect`:

- базовая карточка отеля (звёзды, цена, завтрак, категории номеров) — `collect mock-cards`, `collect mock-rooms`;
- отельеры-персоны (честный, ленивый, приукрашивающий), скрытая истина про питомцев и шторы и **спрос на характеристики**
  (`characteristic_demand`, `source = 'mock'`) — `collect mock-hotelier`; описание — `docs/hotelier.md`.
