# Дизайн: тема в стиле Островка

Источник — Figma, импорт страницы выдачи (шапка `3:729`, карточка отеля `3:2320`). Здесь только токены и правила. Раскладку, роутинг и логику не меняем.

## Токены (Tailwind `theme.extend`)

| Токен | Значение | Где |
|---|---|---|
| `ink` | `#2d3137` | основной текст, заголовки, цена |
| `ink-muted` | `#868686` | вторичный текст, адреса, «за N ночей», старая цена |
| `brand` | `#0e41d2` | основная кнопка (фон), активные элементы |
| `brand-link` | `#1948c4` | ссылки и текстовые кнопки в шапке |

| `brand-soft` | `#dfe7ff` | чипы, бейджи-счётчики |
| `surface` | `#ffffff` | шапка, карточки |
| `surface-muted` | `#f4f4f4` | фон страницы, вложенные панели внутри карточки, кнопки-иконки |
| `line` | `#e5e5e5` | разделители 1px |
| `ok` | `#008900` | «совпало», «гарантировано» (в макете — «Беспл. отмена») |
| `warn` / `warn-bg` | `#b25e00` / `#fff4e5` | «шанс», «под вопросом» — **в макете нет, наше дополнение** |
| `bad` / `bad-bg` | `#c62828` / `#fdecec` | «не совпало», конфликт — **в макете нет, наше дополнение** |

Градиенты (только для акцентов, не больше одного-двух на экран):
- `grad-brand`: `linear-gradient(135deg, #0460ea 20%, #4225f2 87%)` — текст акцента через `bg-clip-text` (в макете «Скидка 10 %», «GURU»). У нас: бейдж «Гуру», метка лучшего варианта.
- `grad-promo`: `linear-gradient(127deg, #c7fb94 22%, #a3f396 87%)` — фон маленьких бейджей (скругление 8 или 4). У нас: «рекомендуем», «гарантия».

Теней в макете нет. Карточки отделяются контрастом: белое на `#f4f4f4`.

## Скругления

`rounded-card` 16px — карточка отеля, крупные блоки. `rounded-inner` 12px — фото, панели внутри карточки, кнопки, поля ввода. `rounded-sm` 8px — кнопки-иконки 32×32, бейджи. `rounded-xs` 4px — мелкие метки (скидка). Чипы — `rounded-full`.

## Отступы

Шкала из макета: 4, 6, 8, 12, 16. Карточка: внешний padding 4, внутренние колонки padding 8, зазор между фото и текстом 4. Вложенная панель: padding 12. Список с иконками: иконка 16, зазор 6, между пунктами 4. Между крупными колонками 16.

## Типографика

Шрифт: `font-sans` = `"Helvetica Neue", Helvetica, Arial, system-ui, sans-serif`. Системный, ничего не скачиваем и не подключаем с CDN. Начертания: 400, 500, 700.

## Компоненты

- **Шапка:** высота 48, фон белый, без тени, снизу разделитель `surface-muted`. Слева логотип (см. ниже) с padding 16. Справа текстовые кнопки 14/500 цвета `brand-link`, высота 34, padding 0 12, скругление 12, при наведении и для активной роли — фон `brand-tint`. Переключатель ролей и плашка «режим без LLM» — в этом же стиле; плашка — чип `brand-soft`.
- **Основная кнопка:** фон `brand`, текст белый 16/500, высота 40, padding 0 12, скругление 12, без рамки. Вторичная — фон `surface-muted`, текст `ink`. Текстовая — как в шапке.
- **Карточка отеля в выдаче:** фон белый, скругление 16, padding 4; слева блок фото или карты 12; справа колонка padding 8: название 16/700, под ним адрес 12 `ink`, строки расстояний 12 `ink-muted`. Блок «что совпало / под вопросом» — вложенная панель `surface-muted`, скругление 12, padding 12, пункты списком «иконка 16 + текст 12/500», цвет текста по статусу (`ok` / `warn` / `bad` / `ink`). Цена 20/700 справа внизу, под ней 12 `ink-muted`. Кнопка действия справа внизу.
- **Оценка или уверенность:** бейдж с белым текстом 16/700 на `brand`, скругление 8, около 35×32; рядом слово (16/700) и подпись (12 `ink-muted`) с выравниванием вправо.
- **Кнопка-иконка** (шортлист и т. п.): 32×32, фон `surface-muted`, скругление 8, иконка 16.

## Иконки, шрифт, логотип: свой файл, иначе запасной вариант

Правило: если файл ассета лежит на месте, используем его, иначе запасной вариант. Отсутствие любого файла не ломает ни сборку, ни страницу. Ассеты из Figma агент не скачивает (ссылки живут 7 дней); файлы кладёт разработчик, если их использование разрешено. Файлы шрифтов кладём, только если лицензия разрешает публикацию в открытом репозитории.

### Где лежат файлы

```
frontend/
  public/
    brand/
      logo.svg            логотип в шапке
    fonts/
      brand-400.woff2     шрифт, обычный
      brand-500.woff2     шрифт, средний
      brand-700.woff2     шрифт, жирный
  src/shared/ui/icon/
    Icon.tsx              единственный компонент иконок: <Icon name="heart" size={16} />
    map.ts                имя → компонент lucide (запасной вариант)
    custom/
      heart.svg           свои иконки, имя файла = name
      …
```

### Иконки

Компонент `Icon` ищет `custom/<name>.svg` через `import.meta.glob('./custom/*.svg', { eager: true, query: '?raw', import: 'default' })`. Если файл есть, вставляет SVG, иначе рендерит lucide-иконку из `map.ts`. Если `custom/` пуста, glob возвращает пустой объект, и сборка не падает. В папке должен лежать `.gitkeep`.

Формат своего SVG:
- одноцветный, `fill="currentColor"` (или `stroke="currentColor"` для контурных): цвет берётся из текста, токены статусов работают;
- есть `viewBox` (лучше `0 0 24 24`), нет атрибутов `width` и `height`: размер задаёт компонент;
- без `<style>`, скриптов, растровых вставок и внешних ссылок.

| `name` (файл `custom/<name>.svg`) | Где | Запасной lucide |
|---|---|---|
| `heart` | шортлист | `Heart` |
| `check` | совпало, гарантировано | `Check` |
| `question` | под вопросом, шанс | `CircleHelp` |
| `cross` | не совпало | `X` |
| `conflict` | источники спорят | `TriangleAlert` |
| `hotelier` | отельер, кабинет | `Building2` |
| `noise` | тишина ночью | `Volume2` |
| `sea` | вид на море, пляж | `Waves` |
| `metro` | метро | `TrainFront` |
| `night` | ночные сервисы | `Moon` |
| `pet` | питомцы | `PawPrint` |
| `compare` | сравнение | `Columns3` |
| `chat` | чат, диалог | `MessageCircle` |
| `search` | поиск | `Search` |

`lucide-react` подключается с точной версией. Размер 16 (в шапке 20), `stroke-width` 2, цвет `currentColor`. Новую иконку добавляют строкой в `map.ts`; свой SVG к ней — по желанию.

### Логотип

`<img src="/brand/logo.svg">` высотой 24–28 px (шапка 48) с `onError`. Если файла нет, `onError` переключает на текстовый знак: квадрат 20×20, скругление 6, фон `grad-brand`, рядом «Бронь без сюрпризов» 16/700 `ink`. Формат: SVG с `viewBox`, без `width` и `height`, горизонтальная компоновка, прозрачный фон.

### Шрифт

В `index.css` три `@font-face` с семейством `Brand` (400, 500, 700) на `/fonts/brand-*.woff2`, `font-display: swap`. Стек: `Brand, "Helvetica Neue", Helvetica, Arial, system-ui, sans-serif`. Если файлов нет, браузер получает 404 и берёт системный шрифт. Формат — только `woff2`.

### Проверка

Сборка и вид страницы проверяются в двух состояниях: пустые `custom/`, `brand/`, `fonts/` (системный вид, lucide, текстовый знак) и с одним тестовым `custom/heart.svg` (тестовый файл после проверки удалить). Ассеты можно класть и после заморозки: код от этого не меняется.
